# GSPack 0.5 - One Material, Many Mods

Bring duplicate resources together and carry existing worlds forward.

- Use unified versions of 113 materials across crafting, loot and inventories.
- Mine matching ores for AllTheOres materials and reduce duplicate ore generation.
- Convert existing worlds with the offline world-conversion tool.
- Complete material quests using matching items from different mods.
- Includes updated PotionsMaster and Sophisticated components.
