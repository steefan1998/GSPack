# GSPack 0.8 - Cores and Cosmos

Development snapshot: new core progression, a Martian frontier and a clearer quest book. Final in-game validation is still pending.

- Follow five core chapters with mod-specific crafting, an FE multiblock and a five-core Powah Creative Singularity.
- Explore Mars with Phobos and Deimos, six Mars ore textures and rare Unobtainium.
- Discover independent Bumblezone and Colossal Reactors chapters in a 43-chapter quest book.
- Keep the first Moon trip accessible; To Orbit is optional and Productive Bees requires no guide book.
- Enjoy 16px core artwork, an animated Singularity, a placeable trophy and seasonal menus.
- Updated category formatting, targeted key-conflict fixes and safer Dev Build synchronization.
